# FarmWatch Pro v3.0

**養豚場 指示評価ダッシュボード**

養豚場の日別事故率・頭数推移をリアルタイムで可視化し、
獣医師の指示・取り組みの効果を定量的に評価するダッシュボードツールです。

---

## 特長

### 基本機能
- **マルチ農場対応** - 複数農場のデータを個別に管理・切り替え・比較
- **CSVインポート** - プレビュー確認・データ整合性チェック付き
- **Excelエクスポート** - 複数シート構成のXLSXファイル出力
- **指示効果分析** - 取り組み前後の死亡率変化を自動計算
- **年度比較** - 前年同月比で改善度を可視化
- **繁殖成績追跡** - 産子数・離乳子数の推移管理

### 高度な分析
- **ヒートマップカレンダー** - GitHub風の色マトリクスで死亡傾向を一覧
- **目標値設定** - 日平均死亡の目標を設定し、達成率をリアルタイム追跡
- **自動アラート** - しきい値超過時に警告通知
- **累計死亡推移** - 目標ペースラインと実績の比較チャート
- **曜日別パターン** - 曜日ごとの事故傾向を自動分析
- **サマリーレポート** - 印刷用レポートをワンクリック生成
- **フルスクリーンチャート** - 任意のチャートを拡大表示

### プロフェッショナル機能
- **ダークモード** - 目に優しいダークテーマに切り替え可能
- **KPIスパークライン** - ダッシュボードカードにミニトレンドグラフ
- **日付メモ機能** - 特定日にメモ（PED発生、ワクチン接種等）を記録
- **農場比較** - 複数農場のKPIを横並びで比較
- **PWA対応** - ホーム画面に追加してアプリのように使用
- **Undo機能** - データ変更を1段階元に戻せる

### 使いやすさ
- **ガイドツアー** - 初回利用時の操作ガイド
- **キーボードショートカット** - 効率的な操作をサポート
- **CSVプレビュー** - インポート前にデータ確認
- **クリップボード入力** - Excelからコピー&ペーストで一括入力
- **テーブルソート** - カラムクリックでソート
- **データ品質チェック** - 欠損日数・ストレージ使用量を可視化
- **自動バックアップリマインダー** - 7日未バックアップで通知

## 使い方

### 起動方法

`dashboard.html` をブラウザで開くだけで使用できます。
推奨ブラウザ: Google Chrome / Microsoft Edge

iPad/スマホではブラウザの「ホーム画面に追加」でアプリのように使用できます。

### 初回セットアップ

1. スプラッシュスクリーン後、ガイドツアーが表示されます
2. 農場名を入力し、管理エリア（離乳舎、分娩舎など）を設定
3. 「デモデータで試す」で機能を確認するか、CSVでデータを取り込み

### データ取り込み

#### 日別データ CSV形式
```
日付,死亡頭数,導入頭数,出荷頭数,移動頭数
2025-01-01,8,0,490,0
2025-01-02,10,450,0,0
```

#### 月別データ CSV形式
```
月,導入頭数,死亡頭数,事故率,週平均死亡
1月,3274,215,6.57,51.19
2月,3550,188,5.30,44.76
```

`samples/` フォルダにサンプルCSVファイルがあります。
CSVインポート画面からテンプレートのダウンロードも可能です。
Excelからのコピー&ペーストによる一括入力にも対応しています。

## 機能一覧

| タブ | 機能 |
|------|------|
| **ダッシュボード** | KPI（スパークライン+目標達成率）、死亡推移、累計推移、月別比較 |
| **日別推移** | ヒートマップカレンダー、死亡グラフ（目標/アラートライン）、曜日別分析、日付メモ |
| **月別比較** | 前年 vs 当年の月別比較（ソート対応テーブル） |
| **繁殖成績** | 産子数・離乳子数の推移、繁殖KPI（ソート対応テーブル） |
| **取り組み管理** | 登録・ステータス管理・テキスト検索 |
| **効果分析** | カスタム期間比較、効果ランキング、レポート生成 |

## キーボードショートカット

| ショートカット | 機能 |
|---|---|
| `Ctrl + E` | データエクスポート |
| `Ctrl + I` | CSVインポート画面を開く |
| `Alt + 1〜6` | タブ切り替え |
| `Escape` | モーダル・メニューを閉じる |

---

## データ管理

- 全データはブラウザの localStorage に保存されます
- JSONエクスポート/インポートでバックアップ・復元
- **Excelエクスポート** で複数シート構成のXLSXファイル出力
- Undo機能で直前の変更を元に戻せます
- データ品質ダッシュボードで欠損日数・ストレージ使用量を確認
- 7日以上バックアップしていない場合、自動でリマインダー表示
